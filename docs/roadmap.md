# Next validation

The current candidate focuses on declared action reachability and horizontal text fit, valid-input reduction and executed saved regressions. See [verification](validation/verification.md) for measured results and limits.

The next useful product input is a real developer adapting the tool to a component they own. The [self-guided trial](validation/trial.md) is prepared for later. Record setup friction, whether a result is useful and replay reliability without filling in unknown outcomes or inferring debugging-time gains.

Use demonstrated integration gaps to choose later work. Other browsers, complex text clipping, keyboard behavior, automatic adapter inference and whole-site auditing are not covered by the current candidate. Do not broaden the engine without a reproducible requirement and appropriate healthy, failing and uncertain controls.
